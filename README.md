# Betrax Studio -- Headphones Landing Page

A static product landing page for a headphones brand ("Betrax") -- front-end coursework project with scroll-reveal animations.

This is a more developed iteration of the earlier version in [WPD](https://github.com/AaryanKoradia/WPD) (`Betrax - Headphones/`), with JavaScript interactivity added.

## View it

Open `index.html` directly in a browser -- no build step or server needed.

## Tech

Plain HTML, CSS, and vanilla JavaScript, using [ScrollReveal](https://scrollrevealjs.org/) (`scrollreveal.min.js`) for scroll animations.
